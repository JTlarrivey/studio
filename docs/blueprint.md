# **App Name**: ProductVerse

## Core Features:

- Product Catalog: Display a sortable and filterable list of products, including name, ID, and relevant sales data.
- Add Product: Provide a form to add new products to the master list, ensuring all required fields are completed.
- Edit Product: Enable users to edit existing product information directly within the application.

## Style Guidelines:

- Primary color: Dark blue (#1A237E) to convey trust and stability.
- Secondary color: Light gray (#EEEEEE) for backgrounds and subtle accents.
- Accent: Teal (#00BCD4) for interactive elements and highlights.
- Use a clean, modern layout with clear separation of sections.
- Use simple, consistent icons to represent product categories and actions.
- Subtle transitions and animations to improve user experience when filtering and sorting.
